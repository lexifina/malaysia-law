# Section 2. Amendment of First Schedule

2. The Criminal Procedure Code [Act 593] is amended in the First Schedule—

(a) by substituting for the item relating to section 305 of the Penal Code the following item: and fine”;

(b) in the item relating to section 306 of the Penal Code, in column 2, by inserting after the words “of suicide” the words “or attempted suicide”; and

(c) by deleting the item relating to section 309 of the Penal Code and particulars relating to it.
