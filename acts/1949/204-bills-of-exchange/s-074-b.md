# Section 74B. Image return document

74B. (1) Where the cheque presented for payment in accordance with section 74A is dishonoured by non-payment, the collecting bank shall, unless the collecting bank returns the cheque itself or the holder requests the return of the cheque itself, issue to the holder an image return document.

(2) Subject to subsection (4), an image return document may be presented for payment to the collecting bank by the holder to whom the image returned document was issued as if that document were the cheque to which it relates.

(3) An image return document shall be deemed to be the cheque to which it relates for the purpose of presentment under subsection (2).

(4) An image return document may be presented under subsection (2) for payment by the holder only if—

(a) the collecting bank states in that document that it is valid for presentment; and

(b) the presentment is made within six months from the date of the cheque or as specified on the cheque.
