# Section 5. New section 130ta

5. The Code is amended by inserting after section 130t the following section:

“Non-application of Offenders Compulsory Attendance Act 1954 and sections 173a, 293 and 294 of the Criminal Procedure Code

130ta. The Offenders Compulsory Attendance Act 1954 [Act 461] and sections 173a, 293 and 294 of the Criminal Procedure Code shall not apply to an offence under this Chapter.”.
