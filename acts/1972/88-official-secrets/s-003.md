# Section 3. Penalties for spying

3. If any person for any purpose prejudicial to the safety or interest of Malaysia—

(a) approaches, inspects, passes over or is in the neighbourhood of, or enters any prohibited place;

(b) makes any document which is calculated to be or might be or is intended to be directly or indirectly useful to a foreign country;

(c) obtains, collects, records, publishes or communicates to any other person any secret official code word, countersign, password or any article, document or information which is calculated to be or might be or is intended to be directly or indirectly useful to a foreign country,

he shall be guilty of an offence punishable with imprisonment for life.
