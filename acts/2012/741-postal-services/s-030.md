# Section 30. Installation of posting box or other collection or delivery equipment

30. (1) A universal service licensee may, for the purpose of providing adequate access points, install any posting box or mail pick up or delivery equipment, stamp vending machine and other similar automatic device in any place to which the public have access.

(2) A universal service licensee before installing any access point shall obtain the approval of the State Authority, local authority or other relevant authority where required to do so.
