# Rule 3. New rule 11A

3. The principal Rules are amended by inserting after rule 11 the following rule:

“Premium for extension of land alienated for a term of years

11A. (1) The rate of premium to be charged upon an extension of land alienated for a term of years under section 90A of the Code shall be as follows:

Category: Agriculture—1/32 x value of land x 1/99 x (holding period of new lease-balance of the holding period of existing lease)

9 Category: Building—

(i) Residential—1/16 x value of land x 1/99 x (new holding period-balance of the existing holding period)

(ii) Commercial—1/8 x value of land x 1/99 x (new holding period-balance of the existing holding period)

(iii) Mixed development—3/32 x value of land x 1/99 x (new holding period-balance of the existing holding period)

Category: Industry—1/8 x value of land x 1/99 x (new holding period-balance of the existing holding period)

For purposes other than above—1/16 x value of land x 1/99 x (new holding period-balance of the existing holding period).

(2) Where an application made under subsection 90A(1) of the Code is approved by the Government, the Registrar shall issue a notice in Form 5A of the Code requiring the applicant to pay premium and any other payments payable within three months from the date the notice is duly served.”.
