# Paragraph 2. Exemption

2. The Minister exempts the following persons from all of the provisions of the Act:

(a) Amazon Data Services Malaysia Sdn. Bhd.;

(b) Amazon Web Services Malaysia Sdn. Bhd.;

(c) Google Asia Pacific Pte. Ltd.;

(d) Google Cloud Malaysia Sdn. Bhd.;

(e) Google Malaysia Sdn. Bhd.;

(f) Microsoft Knowledge Capital Centre Sdn. Bhd.;

(g) Microsoft (Malaysia) Sdn. Bhd.;

(h) Microsoft Payments (Malaysia) Sdn. Bhd.; and

(i) Pearl Computing Malaysia Sdn. Bhd.

Made 28 January 2025
