DESCRIPTION OF CLASSES OF USE

Classes of Use Description

Class A1 - Residential unit Any type of residential unit except serviced apartment and Small Office Home Office (SOHO)

Class A2 - Quarters Any type of quarters for public servants or employees of statutory bodies or other bodies

Class A3 - Hostel Any type of rented hostel

Class A4 - Care home Any type of residential unit used as a facility for persons with disabilities, aged persons, children or other groups of people requiring extra care, attention or supervision which is not associated to or part of any healthcare facility

Class A5 - Home-based business Any type of residential unit except serviced apartment and SOHO which is also used for carrying out a business with not more than two employees

Class B1 - General retail Any commercial space used for general retails

Class B2 - Business Any commercial space used for a business

Class B3 - Office Any commercial space used for operating an office

Class B4 - Financial institution Any commercial space used for financial or banking activities

68 Classes of Use Description

Class B5 - Food and drink Any commercial space used for sale of food and drink

Class B6 - Entertainment Any type of premises used for any form of entertainment except theme park

Class B7 - Wellness Any commercial space used for wellness activities

Class B8 - Gambling Any commercial space used for gambling activities

Class B9 - Theme park Any type of indoor and outdoor theme parks

Class B10 - Tourist Any type of tourists accommodation accommodation

Class B11 - Serviced apartment Any type of serviced apartment

Class B12 - Small Office Home Any commercial space used for operating an Office (SOHO) office and for residential purposes in one unit

Class B13 - Supermarket Any type of supermarket

Class B14 - Departmental store Any type of departmental store

Class B15 - Hypermarket Any type of hypermarket

Class B16 - Funeral services Any type of premises used for funeral services

69 Classes of Use Description

Class C1 - Showroom Any type of showroom

Class C2 - Packaging, storage Any type of premises used for packaging, and distribution storage and distribution of goods

Class C3 - Recycling Any type of premises used for recycling of materials

Class C4 - Petrol station Any petrol station including its retail establishments

Class C5 - Engineering work Any type of premises used for engineering works

Class C6 - Vehicles repair and Any type of premises used for maintenance and service repair services of motor vehicles

Class C7 - Manufacturing and Any type of premises used for manufacturing, processing processing and production of goods

Class C8 - Publishing and Any type of premises used for publishing and printing printing services

Class C9 - Technology, research Any type of premises used for technology, and development research and development activities

Class C10 - Batching plant Any site used for batching cement

Class D1 - Health facility Any type of premises used for provision of healthcare services or health-related services

70 Classes of Use Description

Class D2 - Religious facility Any religious facility

Class D3 - Education facility Any type of educational institution for any level of education

Class D4 - Civic use Any type of premises used for public and culture activities except community facility

Class D5 - Community facility Any type of premises used for specific community activities

Class D6 - Sports and recreation Any type of premises used for sports and facility recreational activities except golf facility

Class D7 - Golf facility Any area used as a golf facility

Class D8 - Institution and Any type of premises used for administration of organization the Government or other organizations except for emergency and security purposes

Class D9 - Shelter home or Any type of premises used as a care and institution rehabilitation facility provided by the Government

Class D10 - Emergency and Any type of premises used for operation of the security Government agencies dealing with emergency and security matters

71 Classes of Use Description

Class E1 - Transport facility Any type of premises used as a transportation station or terminal including its retail establishments

Class E2 - Park and ride Any type of premises used as a park and ride facility

Class E3 - Parking Any type of premises used for parking of any motor vehicles

Class E4 - Public utility Any type of premises used as a public utility facility except solid waste facility

Class E5 - Solid waste facility Any type of premises used as a solid waste management facility

Class E6 - Slaughtering centre Any type of premises used for slaughtering of birds
