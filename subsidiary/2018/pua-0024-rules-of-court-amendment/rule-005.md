# Rule 5. Authentication Code (O.31A, r.5)

5. (1) Before using the e–Lelong System, the registered user shall apply to the Registrar for identification names and authentication codes to be assigned to him.

(2) The registered user shall register his particulars with the Registrar and acknowledge in writing safe receipt of the identification name and authentication code assigned to him by the Registrar.

(3) The registered user shall inform the Registrar in writing of any change of his particulars.
